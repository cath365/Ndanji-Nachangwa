CMS

This dashboard edits the actual portfolio pages. Choose a page, change its words, links or images, preview it, then publish. Publishing commits the updated page to GitHub so the connected Vercel project can redeploy it.

Git history acts as a safety net. Each publish creates a repository commit, so previous versions can be recovered if needed.
